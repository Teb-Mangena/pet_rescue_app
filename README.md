# PetRescue App 🐾

A full-stack web application designed to streamline reporting, tracking, and hand-over processes for missing and found pets between community members, pet owners, and SPCA managers.

## 🚀 Getting Started & Installation Guide

Follow these steps to set up, seed, and run the application locally from scratch.

### Prerequisites
* [Node.js](https://nodejs.org/) installed on your machine.
* A running local MySQL database server (e.g., MySQL Workbench or XAMPP).

---

### Step 1: Install Dependencies
Open your terminal and install dependencies for both the backend and frontend directories.

```bash
# 1. Install backend dependencies
cd backend
npm install

# 2. Install frontend dependencies
cd ../frontend
npm install
